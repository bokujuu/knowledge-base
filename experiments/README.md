# experiments

検証結果・試行錯誤の記録を置きます。

## 置くもの

- コマンドや設定を試した結果（再現手順付き）
- PoC の所感・失敗ログ
- 「動いた / 動かなかった」の事実記録

## コードとの境界

- **実装本体** → 各プロジェクトリポジトリ
- **検証の記録（手順・結果・所感）** → このフォルダ

## 命名例

```text
experiments/2026-06-17-cloud-agent-install.md
experiments/uv-sync-on-windows.md
```

## 推奨フォーマット

```markdown
# 検証タイトル

- 日付: YYYY-MM-DD
- 環境: OS / ツールバージョン

## 目的

## 手順

## 結果

## 所感
```
