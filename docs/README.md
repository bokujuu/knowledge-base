# docs

手順書・ガイド・長期に参照するドキュメントを置きます。

## 置くもの

- ツールの使い方（Cursor、Git、各種 CLI など）
- 運用ルール・ワークフローの説明
- 複数カテゴリにまたがる横断ドキュメント

## 置かないもの

- 1 回きりの短いメモ → `notes/`
- 外部サイトの要約だけ → `references/`
- 調査の途中経過 → `research/` または `experiments/`
