# Why GitHub is the library

## Judgment

Put durable agent judgments in this git repo. Do not grow `AGENTS.md` or User Rules. Do not treat Gmail or chat as the source of truth.

A new session reconnects through [desk.md](../desk.md). `ctx` finds the original transcript; this library stores the distilled rule.

## Why not the code repo

Mixing research into an app repo bloats README, mixes lifecycles, and leaks project B into project A context.

## Not proven

External notes do not by themselves explain Codex cache rates. Keep that claim out of the desk.
