# Anima 見た目変換 LoRA

Anima Base 上で、参照画像の見た目へ全画面で寄せる LoRA の学習判断である。対象は Depth 面の単純化と、線画・減色・発光のような画風変換である。薄い概念スライダーと、同一ノイズの長尺コピー機のあいだを取る。

## 目的

変換先画像と元画像の差を、常用の推論倍率で人物と構図を残したまま出したい。変換の逆も、同じ差の向きをひっくり返して使いたい。

## 結果

同一ノイズで各画像を短尺過学習し、変換先から元画像を引いて SVD で平均する方式が、全画面効果と構図保持を常用倍率で両立した。ペア数は 15、差分で元画像側に掛ける係数は 0.8 が採用である。7 ペアでも向きは同じだが、小物と構図の安定は 15 の方が上である。

同一ノイズの長尺コピー機は、同じ評価条件で全画面効果の上限になる。短尺 15 ペアはそれより弱いが、学習時間が桁違いに短く、常用としては足りる。

同じ過学習対から符号を入れ替えてマージすると、グレー化の逆、単色化の逆、画風の逆が取れる。推論倍率の符号反転は、彩度戻しの一部を除き、格子や均一な布目へ崩れ、逆変換の代用にならない。

画風原稿では、色トーンは元画像へ不透明度 0.65 で載せたものが、黒ハッチより絵として自然だった。2値は大津の黒とドッジ線画の黒の論理和が、単純閾値より形を残した。極小発光と面発光は別の変化なので、混ぜると軸が潰れる。

## 最適とする理由

短尺過学習は、変換先と元画像を同じノイズ・同じ step で点として覚える。差分はその点同士の差なので、残差勾配を少しずつ積むより更新が大きい。15 ペアの SVD は、1 枚過学習の構図引き込みを平均で弱めつつ、面の単純化は残す。

差分係数 0.8 は、0.5〜0.6 より変化が強く、係数 1.0 や推論倍率 4 まで上げる前に止まる。既存の 0.7 差分を 0.8 に付け替えるだけでも強度が上がる。追加の過学習より安い。

完成 LoRA を概念スライダーや直接差分と混ぜると、全画面の面変化が薄まる。主成分がすでに短尺コピーにあるため、混ぜる相手が希釈になる。

ペアを 15 より増やしても、7 から 15 へ増やしたときほどの安定化は見込めない。平均の延長であって、新しい情報量ではない。

## 悪化する操作

| 操作 | 起きること | 理由 |
|------|------------|------|
| 過学習を数百 step の長尺コピーに戻す | 上限品質には近づきうるが、常用の時間対効果を壊す | 50 step で実用域に入ったあとの追加 step は、面効果より過学習の癖を増やす |
| 残差勾配を直接積む、または係数だけ後から何桁も掛ける | 変化が極小、あるいはノイズや黒潰れ | 一次近似の更新は CAME 50 step より桁が小さい。ペア平均のあと、向き自体が倍率では戻らない |
| 完成 LoRA をスライダーや直接差分と混合する | 単体より薄い | 全画面成分が希釈される |
| 損失を残差に置き換える、σ 窓や deep block や modulation だけに載せる | 格子ノイズ、または人物と室内の喪失 | 再構成コピーが使っていた更新の分布から外れる |
| スライダー目的をコピー機と同じ学習率で長く回す | 人体が崩れる | スケールが過学習側へ寄る。冷やすなら学習率 5e-5、150 step 付近がバランスするが、全画面 Depth には届かない |
| 推論倍率 4 | 白飛び、多重人物 | 強度を学習ではなく倍率に寄せている |
| 推論倍率 −1 を逆変換にする | 高周波格子や単色布目へ崩壊しやすい | 過学習 LoRA の符号反転は写像の逆ではない。逆は差分の正負を入れ替えて作る |
| 差分係数 0.5〜0.6 | 保持は増えるが変化が弱い | 元画像側の引きが足りない |
| SVD rank 128 | 容量に見合う改善がない | 平均の主成分は rank 64 で足りる。rank 32 は軽量寄りで、常用の置き換えではない |
| 色トーンを黒線ハッチにする | 漫画トーンではなく汚れに見える | 同色相の明暗ペアで縞を作り、元画像へ 0.65 で合成する方が色面を保つ |
| 2値を固定閾値だけにする | 形が欠けたり、面が潰れる | 大津とドッジ線の黒を論理和すると輪郭と影が残る |
| 極小発光と面発光を 1 軸に混ぜる | どちらの変化も中途半端になる | 局所ハイライトと面の白飛びは別の差分である |

## ツールとパラメータ

学習実装は Anima 向け sd-scripts、ネットワークは DiT 本体のみの LoRA（LLM adapter なし）。最適化は CAME、学習率 1.6e-4、スケジューラは constant。rank 64、alpha 1、50 step、batch 2、1024 バケット、空キャプション、共有ノイズ seed 42、bf16、latent と text encoder の cache。1 本あたり約 2.7 分。

差分は変換先 1.0 から元画像 × 0.8 を引く。複数ペアは等比率、SVD の新 rank は 64。逆変換は元画像 1.0 から変換先 × 0.8 を引く。元画像側の過学習は、画素が同じなら軸をまたいで再利用する。

推論の常用倍率は 0.7 と 1。強い寄せの確認に 2。評価は同一プロンプト、同一ベース、同一 seed、解像度 1536 で固定する。通過は、倍率 1 で目的の変化が見え、人物 1 名と室内構造が残ることである。

画風原稿の採用パラメータは次である。

- 色トーン: 平坦化のあと k-means 8 色。肌（高輝度・低彩度）は面のまま。同色相の明暗で角度付き縞を載せ、元画像へ不透明度 0.65 で合成する
- 2値: 大津で黒になった画素と、ドッジ線画の輝度が 180 未満の画素の論理和
- パレット: 4 / 6 / 8 色。12 色は減色として弱い
- メタル: 6 色パレット 0.55 と銀反射 0.45
- Depth フォグ: 近景が明るい Depth を使う
- 発光: 極小（tophat）と面（bright-pass）は別軸、中程度
