# knowledge-base

Agent library: judgments that should survive a new chat. Not a dump of every note.

Always-on entry: [docs/desk.md](docs/desk.md).

Procedures that run in every repo: [bokujuu_cursorsetup](https://github.com/bokujuu/bokujuu_cursorsetup).

## Layout

```text
docs/desk.md              reconnect index (keep small)
docs/library/             judgments that change the next agent
docs/inbox/               seen once
docs/promotion-ledger.md  inbox → library → skill
```

Search prior chats with `ctx search` ([ctxrs/ctx](https://github.com/ctxrs/ctx)) before writing a duplicate note.
