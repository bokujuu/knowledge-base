# research

調査結果・比較検討・意思決定の記録を置きます。

## 置くもの

- 技術選定の比較表と結論
- 「なぜ A ではなく B か」の記録
- 調査メモのまとめ（仕事・趣味・AI 関連を問わない）

## 推奨フォーマット

```markdown
# タイトル

- 日付: YYYY-MM-DD
- ステータス: 調査中 / 結論あり / 保留

## 背景

## 調査内容

## 結論・次のアクション
```

## 命名例

```text
research/2026-06-17-github-knowledge-limits.md
research/cursor-agent-observability.md
```

## 関連

GitHub 活用の限界を意識し、コードリポジトリではなくここに調査結果を残す運用を推奨します。
